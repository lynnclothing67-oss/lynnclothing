# **App Name**: PetalCart

## Core Features:

- Browse Collections: Display a catalog of women's clothing organized by category.
- View Product Details: Provide detailed product information pages, including images and descriptions.
- Contact Support: Integrate a direct contact option with support via WhatsApp.
- Admin Dashboard: Enable administrators to manage products.
- AI-Powered Product Recommendations: Suggest related items to increase user engagement.

## Style Guidelines:

- Primary color: Soft rose (#F4B4B4) to evoke femininity and gentleness.
- Background color: Pale blush (#F9E4D8) to create a warm and inviting feel.
- Accent color: Rose gold (#B76E79) for highlights and interactive elements.
- Font pairing: 'Playfair' (serif) for headlines, and 'PT Sans' (sans-serif) for body text.
- Use elegant and minimalistic icons in rose gold to complement the color palette.
- Employ a clean, spacious layout with ample whitespace to showcase the clothing items.
- Incorporate subtle animations, such as smooth transitions and hover effects, to enhance the user experience.
